# سیستم قیمت‌گذاری خودکار (Auto Pricing System)

## نمای کلی پروژه

این سیستم یک راه‌حل کامل برای قیمت‌گذاری خودکار محصولات در ERPNext است که با پشتیبانی کامل از زبان فارسی و ویژگی‌های پیشرفته طراحی شده است.

## ویژگی‌های اصلی

### 1. قیمت‌گذاری هوشمند
- **محاسبه خودکار قیمت**: بر اساس BOM و هزینه‌های مواد
- **قیمت‌گذاری دستی مواد**: امکان تعیین قیمت دستی برای مواد خاص
- **جایگزینی مواد**: استفاده از مواد جایگزین با قیمت‌های متفاوت
- **اولویت‌بندی قیمت**: دستی > جایگزین > BOM > پیش‌فرض

### 2. استراتژی‌های قیمت‌گذاری
- **قیمت پایه**: قیمت بر اساس هزینه + حاشیه سود
- **قیمت با تخفیف**: اعمال تخفیف با محاسبه markup
- **قیمت قسطی**: محاسبه قسط با بهره
- **قیمت ترکیبی**: ترکیب تخفیف و قسط

### 3. محاسبات پیشرفته
- **کمیسیون**: محاسبه کمیسیون و سود خالص
- **قسط**: محاسبه پیش‌پرداخت، قسط ماهانه، و بهره
- **تخفیف**: محاسبه markup مورد نیاز برای تخفیف
- **رند کردن قیمت**: رند کردن قیمت‌های نهایی

### 4. تحلیل و گزارش‌گیری
- **داشبورد تعاملی**: نمایش آمار و چارت‌های تحلیلی
- **تحلیل سودآوری**: شناسایی محصولات سودآور و ضررآور
- **مقایسه با بازار**: مقایسه قیمت‌ها با price list‌های دیگر
- **جزئیات قیمت‌گذاری**: نمایش تفصیلی اجزای قیمت

## نحوه استفاده

### 1. ایجاد Auto Price List جدید
```
1. رفتن به Auto Price List
2. ایجاد سند جدید
3. انتخاب استراتژی قیمت‌گذاری
4. تنظیم پارامترها (حاشیه سود، تخفیف، قسط)
5. اضافه کردن آیتم‌ها
```

### 2. تنظیم قیمت‌های دستی
```
1. در بخش Manual Material Prices
2. انتخاب آیتم مورد نظر
3. وارد کردن قیمت دستی
4. ذخیره سند
```

### 3. محاسبه قیمت‌ها
```
1. کلیک روی دکمه "محاسبه قیمت‌ها"
2. سیستم خودکار قیمت‌ها را محاسبه می‌کند
3. نتایج در جدول آیتم‌ها نمایش داده می‌شود
```

### 4. مشاهده داشبورد
```
1. کلیک روی "نمایش داشبورد قیمت‌گذاری"
2. مشاهده آمار کلی و چارت‌ها
3. تحلیل سودآوری محصولات
```

### 5. نمایش جزئیات قیمت‌گذاری
```
1. کلیک روی "جزئیات قیمت‌گذاری"
2. مشاهده تفکیک کامل قیمت هر محصول
3. بررسی اجزای سود، بهره، کمیسیون
```

## فرمول‌های محاسباتی

### قیمت پایه
```
قیمت فروش = هزینه کل × (1 + حاشیه سود / 100)
```

### قیمت با تخفیف
```
Markup مورد نیاز = تخفیف / (1 - تخفیف / 100)
قیمت با Markup = قیمت پایه × (1 + Markup / 100)
قیمت نهایی = قیمت با Markup × (1 - تخفیف / 100)
```

### قیمت قسطی
```
مبلغ پیش‌پرداخت = قیمت × (پیش‌پرداخت / 100)
مبلغ قسط = قیمت - پیش‌پرداخت
قسط ماهانه = مبلغ قسط × (نرخ بهره × (1 + نرخ بهره)^تعداد ماه) / ((1 + نرخ بهره)^تعداد ماه - 1)
```

### کمیسیون
```
مبلغ کمیسیون = قیمت فروش × (درصد کمیسیون / 100)
سود خالص = سود - کمیسیون
```

## نکات مهم

### بهترین شیوه‌ها
1. **همیشه قیمت‌های دستی را اول تنظیم کنید**
2. **حاشیه سود منطقی انتخاب کنید (15-30%)**
3. **تنظیمات قسط را دقیق وارد کنید**
4. **از داشبورد برای تحلیل استفاده کنید**

### محدودیت‌ها
- حداکثر حاشیه سود: 100%
- حداقل حاشیه سود: 5%
- حداکثر تخفیف: 50%
- حداکثر مدت قسط: 60 ماه

### عیب‌یابی
1. **بررسی console browser برای خطاهای JavaScript**
2. **بررسی لاگ‌های سرور برای خطاهای Python**
3. **اطمینان از وجود BOM برای آیتم‌ها**
4. **بررسی صحت تنظیمات قسط و تخفیف**
